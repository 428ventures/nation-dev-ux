# nation.dev — UX prototypes

Interactive, self-contained UX prototypes for a skill-first tech community.

- **Nation Prism** — `/` — hue-shifting workspace: every section owns a color and the whole interface re-tints as you move.
- **Nation Air** — `/air.html` — the calm, spacious baseline.

All content is fictional demo data. Single-file HTML, no build step, no dependencies.
- **Nation Spectrum** (color worlds): `spectrum.html`
